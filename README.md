# Atrium

One quiet library for every game on your PC. Atrium gathers your Steam, Epic Games, GOG and Ubisoft Connect games into a single liquid-glass launcher, with Steam always first.

**Website:** https://lolassion.github.io/atrium/

**Download:** grab `Atrium-Setup.exe` (installer) or `Atrium-Portable.exe` (no install) from the [latest release](https://github.com/lolassion/atrium/releases/latest).

Windows may show "Windows protected your PC" the first time because the app isn't code-signed yet. Choose **More info → Run anyway**.
